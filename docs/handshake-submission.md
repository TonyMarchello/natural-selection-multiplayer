## Project description

Natural Selection is a multiplayer evolution roguelike where animals explore a shared habitat, gather resources, evolve, and compete. When an animal is defeated, that player returns as a named disease with a new objective: spread infection before the remaining species develop immunity and neutralize it. Every match creates a new opponent, and the server keeps both browsers synchronized through rematches, role changes, mutations, and endgame results.

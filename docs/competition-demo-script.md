# Natural Selection — competition demo script

## 90-second walkthrough

1. Open the public URL: https://natural-selection.onrender.com/
2. In browser one, enter the field name `Host`, choose Deer, and create a refuge.
3. Copy the lobby code. In browser two, enter `Guest`, choose Wolf, paste the code, and join.
4. Both players press Ready. Explain that the lobby will not start until every player is ready.
5. Start the match. Move with arrow keys or WASD, then gather a labeled food, water, or energy resource.
6. Point out the target readout and challenge action. Show that the server-authoritative state updates in both browser sessions.
7. Demonstrate evolution: gather enough resources, open Adapt, and choose a mutation with a trade-off.
8. Demonstrate the central loop: an animal can defeat another animal, the defeated player returns as a named disease, and the animal team can gather resources to neutralize it.
9. Finish the match and show the synchronized result and match summary in both browsers.
10. Use Rematch, then repeat the ready/start flow to prove the same lobby can run another round.

## Backup narration

“Natural Selection is a multiplayer evolution roguelike where every victory changes the next threat. Animals explore a shared habitat, gather resources, evolve, and fight. When an animal is defeated, that player returns as a disease with a new objective. The game is built around readable choices, synchronized multiplayer state, and a fast rematch loop.”
